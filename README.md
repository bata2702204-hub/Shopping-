# סל חכם 🛒

רשימת קניות חכמה עם השוואת מחירים בין רשתות השיווק בישראל: שופרסל, רמי לוי, ויקטורי, יוחננוף וטיב טעם.
האפליקציה בנויה ב-React, Tailwind CSS ו-Lucide, מותאמת קודם כל לנייד, בעברית מלאה (RTL) ועם מצב כהה ובהיר.

## מה יש באפליקציה
- **הוספה מהירה**: מקלידים "חלב, ביצים, 2 עגבניות" ולוחצים Enter. כל מוצר מקוטלג אוטומטית למחלקה, ומוצגות הצעות השלמה מהקטלוג.
- **מחלקות**: ירקות ופירות, מאפים, בשר ודגים, מוצרי חלב, יבשים ומזווה, ניקיון ותחזוקה, קפואים ו"אחר".
- **ניהול פריטים**: סימון, כמות (+/−), עריכה (שם, כמות, מחלקה) ומחיקה עם אפשרות "בטל". מוצר שמוסיפים פעמיים מצטבר לכמות של הפריט הקיים.
- **השוואת מחירים**: עלות הסל בכל רשת, הרשת הזולה ביותר, החיסכון לעומת היקרה ביותר, טבלת מחירים לפי מוצר וטיפ לקנייה מפוצלת בין רשתות.
- **מצב קניות**: המחלקות מסודרות לפי סדר ההליכה בסופר, עם אזורי לחיצה גדולים, פס התקדמות וסכום מצטבר בעגלה לפי הרשת שנבחרה. מחלקה שהושלמה מתקפלת.
- הנתונים נשמרים בדפדפן של המכשיר (localStorage).

## הרצה מקומית
```bash
npm install
npm run dev      # שרת פיתוח
npm test         # בדיקות יחידה (קטלוג ומחשבון סל)
npm run build    # בנייה לתיקיית docs/
```

## העלאה ל-GitHub Pages
התיקייה `docs/` מכילה את הגרסה הבנויה ונשמרת ב-repo.
ב-GitHub נכנסים ל-Settings ← Pages ← Source: "Deploy from a branch", בוחרים Branch `main` ותיקייה `/docs` ושומרים.
אחרי כדקה האפליקציה זמינה בכתובת `https://<שם-המשתמש>.github.io/shopping/`.
בטלפון פותחים את הכתובת ואז תפריט ← "הוסף למסך הבית".

אחרי כל שינוי בקוד מריצים `npm run build` ומעלים גם את `docs/`.

## מבנה הקוד
```
src/
  data/        categories.js, chains.js, products.mock.js  ← קטלוג ומחירי דמה
  services/    categorizer.js  ← קטלוג אוטומטי (עברית, רבים/יחיד, מילות מפתח)
               priceService.js ← שכבת השירות למחירים + computeBasket
  store/       ShoppingContext.jsx ← ניהול מצב (useReducer + Context) ושמירה
  hooks/       usePrices.js
  components/  ListView, CompareView, ShopView, QuickAdd, ui
```

## חיבור למחירים אמיתיים
המחירים כרגע הם **הדמיה ריאלית** ולא מחירים עדכניים.
כל הממשק פונה רק ל-`priceService`, ולכן כדי לעבור לנתונים אמיתיים צריך לכתוב Provider עם אותן מתודות (`getChains`, `getQuotes`) ולהחליף שורה אחת בסוף `src/services/priceService.js`:

```js
export const priceService = createPriceService(new TransparencyApiProvider({ baseUrl: 'https://your-backend' }));
```

לפי חוק המזון (שקיפות מחירים), הרשתות מפרסמות כל יום קובצי XML (PriceFull ו-Promo).
אי אפשר להוריד אותם ישירות מהדפדפן, ולכן צריך שרת קטן שיוריד ויפענח אותם ויחזיר JSON בפורמט שמתואר ב-`TransparencyApiProvider`.
